# WhiteRoom Focus Effect Specification

## Purpose

Simulates peripheral-vision blur: the center of each cell appears sharp while the surrounding area blurs progressively. The blur center can move between a sequence of waypoints to create a "guided gaze" animation.

---

## Placement

- UI: bottom of the **Filter category (blue)**, after the Blur Effect section
- `titleColor`: `#82b0ff` (filter category unified color)

---

## Type Definition

```typescript
export type FocusBlurPattern = 'circular' | 'horizontal' | 'vertical'

export type FocusWaypoint = {
  x: number   // normalized 0–1 (0 = left edge of cell)
  y: number   // normalized 0–1 (0 = top edge of cell)
}

export type FocusEffect = {
  enabled: boolean
  pattern: FocusBlurPattern
  viewSizeRatio: number      // clear-center radius; 0.1–1.0; default 0.4
  blurStrength: number       // BlurFilter strength; 0–100; default 20
  waypoints: FocusWaypoint[] // up to 8 points; empty = static at effectCenter
  movementSpeedSec: number   // seconds to travel one segment; 0.5–30; default 3
}
```

Add `focus: FocusEffect` to `CellEffects`.

---

## Default Values

```typescript
focus: {
  enabled: false,
  pattern: 'circular',
  viewSizeRatio: 0.4,
  blurStrength: 20,
  waypoints: [],
  movementSpeedSec: 3,
}
```

## Rendering

### Layer

Add `focusLayer: PIXI.Container` to `container` after `fogLayer`, before `censorLayer`.

```
container
  ...
  |- fogLayer     [6]
  |- focusLayer   [7]  ← new
  |- censorLayer  [8]  ← new (see WR-CensorEffect.md)
  |- guideLayer   [9]  ← was [7]
```

### Composition

1. **Blur sprite** (`focusBlurSprite: PIXI.Sprite`) — references the same texture as `imageLayer`'s sprite; has a `PIXI.BlurFilter` with `strength = blurStrength` applied; added as a child of `focusLayer`.
2. **Gradient mask** (`focusMaskSprite: PIXI.Sprite`) — generated by `createFocusMaskTexture()`; set as `focusBlurSprite.mask`. Black pixels (0) = sprite transparent → the sharp `imageLayer` beneath shows through. White pixels (255) = sprite opaque → blurred version is visible.

### Mask Texture Generation (`createFocusMaskTexture`)

Generate via `PIXI.RenderTexture` + `PIXI.Graphics` drawing, added to `pixiEffects.ts`.

Signature: `createFocusMaskTexture(pattern, viewSizeRatio, cx, cy, w, h): PIXI.Texture`

| `pattern` | Method |
|---|---|
| `circular` | Radial gradient centered at `(cx, cy)`. Black inside radius `r = viewSizeRatio × min(w,h) / 2`; white outside. Feather width ≈ 30% of `r`. |
| `horizontal` | Bi-directional linear gradient on X axis. Center band of width `viewSizeRatio × w` is black; left and right edges are white. |
| `vertical` | Same as `horizontal` rotated 90°. |

Regenerate the texture when `pattern`, `viewSizeRatio`, cell size, or center position changes.

### Center Position

`CellRenderer` holds `focusCurrentX` and `focusCurrentY` (normalized 0–1).

- 0 waypoints → use `effectCenter.x / y` (static)
- 1 waypoint → that point (static)
- 2+ waypoints → animated by `tickFocus()`

### Animation (`tickFocus`)

```
each frame:
  focusWaypointProgress += deltaMs / (movementSpeedSec × 1000)
  if focusWaypointProgress >= 1.0:
    focusWaypointProgress -= 1.0
    focusWaypointIndex = (focusWaypointIndex + 1) % waypoints.length

  t = easeInOutSine(focusWaypointProgress)
  from = waypoints[focusWaypointIndex]
  to   = waypoints[(focusWaypointIndex + 1) % waypoints.length]
  focusCurrentX = lerp(from.x, to.x, t)
  focusCurrentY = lerp(from.y, to.y, t)
```

`easeInOutSine`: `t => -(Math.cos(Math.PI * t) - 1) / 2`

### Guide Display

Draw on `guideLayer` while the effect is enabled or pick mode is active:
- Numbered circle (radius 8 px, white stroke) at each waypoint position
- Small crosshair marker at the current `(focusCurrentX, focusCurrentY)`

## Waypoint Pick Mode

### appStore State

Add `focusWaypointPicking: boolean`. Mutually exclusive with all other pick modes (set others to `false` when activating).

### Behavior

1. User presses "Add point" → `focusWaypointPicking = true`.
2. On click inside the active column (`handleMouseDown`):
   - Compute normalized `(x, y)` within the cell.
   - Call `setCellEffect(cellId, 'focus', { waypoints: [...current, {x, y}] })`.
   - Auto-exit pick mode when 8 points are reached.
3. `Escape` or out-of-column click → cancel (extend `cancelPickMode`).

---

## Profile Compatibility

Add to `mergeEffectsWithDefaults`:
```typescript
focus: { ...DEFAULT_EFFECTS.focus, ...effects?.focus },
```
Old profiles (no `focus` field) load with defaults (`enabled: false`).
